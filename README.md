# ms1ee.github.io

Personal homepage of Minseok Lee — https://ms1ee.github.io

Built with [al-folio](https://github.com/alshedivat/al-folio) (Jekyll). Pushing to `main` builds the site with GitHub Actions and deploys it to the `gh-pages` branch.

## Where to edit

| What | File |
| --- | --- |
| Name, site settings | `_config.yml` |
| About page (bio, subtitle, location) | `_pages/about.md` |
| Profile photo | `assets/img/prof_pic.jpg` |
| CV page | `_data/cv.yml` |
| CV PDF download button | put the PDF in `assets/pdf/` and uncomment `cv_pdf` in `_pages/cv.md` |
| Social icons (email, GitHub, Scholar, ...) | `_data/socials.yml` |

More customization options: `docs/CUSTOMIZE.md`.
